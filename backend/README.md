## 项目简介

TerraiNav 是一个智能地形分析系统，通过AI大模型识别地形要素，采用FAHP模糊层次分析法评估威胁等级，并使用ACO蚁群算法规划最优无人机巡逻路线。

### 核心功能

| 功能模块 | 技术方案 | 说明 |
|---------|---------|------|
| 地形识别 | 阿里云百炼 VL模型 | 切割图片并行分析，识别高程/类型/坡度等 |
| 威胁评估 | FAHP模糊层次分析法 | 6因子权重计算威胁分数 |
| 路径规划 | ACO蚁群算法 | TSP求解最优巡逻路线 |
| 可视化 | Matplotlib | 热力图+路线图 |

## 快速开始

### 1. 安装依赖

```bash
pip install openai pillow numpy pandas matplotlib ttkbootstrap flask flask-cors
```

### 2. 配置API密钥

**方式一：环境变量（推荐）**
```bash
# Linux/Mac
export DASHSCOPE_API_KEY="sk-your-api-key"

# Windows PowerShell
$env:DASHSCOPE_API_KEY="sk-your-api-key"
```

**方式二：代码中直接配置**
```python
# agent.py 或 main.py 中修改
api_key = "sk-your-api-key"
```

> 获取API Key：[阿里云百炼控制台](https://bailian.console.aliyun.com/)

### 3. 运行方式

#### 命令行模式
```bash
python main.py
```

#### GUI模式
```bash
python main_gui.py/gui/gui.py
```

#### Web模式
```bash
python app.py
# 访问 http://localhost:5000
```

## FAHP威胁评估因子

系统采用模糊层次分析法（FAHP），综合6个因子评估威胁等级：

| 序号 | 因子 | 权重 | 评分规则 |
|-----|------|------|---------|
| 1 | 高程 | 0.1151 | 越高分数越高 |
| 2 | 地形类型 | 0.1536 | 制高点>陡坡>冲沟>...>道路 |
| 3 | 坡度 | 0.2009 | 越陡分数越高 |
| 4 | 隐蔽性 | 0.0849 | 高>中>低 |
| 5 | 通视 | 0.0606 | 好>中>差 |
| 6 | 威胁等级 | 0.3849 | 3级>2级>1级 |

## 本地调试与 Railway 部署

### 本地调试
1. 进入 `backend` 目录：
   ```bash
   cd backend
   ```
2. 创建 `.env` 并填写密钥：
   ```bash
   copy .env.example .env
   ```
3. 安装 Python 依赖：
   ```bash
   pip install -r requirements.txt
   ```
4. 运行后端服务：
   ```bash
   python api.py
   ```
5. 启动前端开发服务器：
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```
6. 打开浏览器访问 `http://localhost:5173`，前端默认会请求 `http://localhost:5000`。

### Railway 部署
1. 在 Railway 创建新项目并选择从仓库部署。
2. 指定 `backend` 文件夹为部署根目录。
3. 设置环境变量：
   - `DASHSCOPE_API_KEY` = 你的阿里云百炼密钥
4. Railway 会自动使用 `backend/Procfile` 启动：
   - `web: gunicorn api:app`
5. 部署后，前端可以通过 Vercel 的环境变量指向 Railway 后端地址。
